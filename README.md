# ABAMCA PROJECT

## Introduction
The objective of the <a href="https://www.insisoc.uva.es/index.php/ins-abamca-home/" target="_blank">**ABAMCA project**</a> is to apply combinatorial auctions and agent-based modeling methodologies to develop a platform that reduces the current imbalance between supply and demand in the additive manufacturing market for subcomponents.

In the context of additive manufacturing, the ABAMCA project aims to develop and explore innovative methodologies for allocating industrial customers—companies that subcontract the production of subcomponents—to suppliers, i.e., manufacturers qualified to produce those subcomponents using 3D printing. The project focuses on leveraging combinatorial auction techniques and agent-based modeling to address the current imbalance between supply and demand in the additive manufacturing market for subcomponent production.

The main deliverable will be a pilot marketplace platform where customer companies can request the production of specific subcomponents, while manufacturers can bid on combinations of orders they wish to fulfill, optimizing the utilization of their additive manufacturing machines. The platform’s effectiveness will be validated through application to various case studies involving Spanish additive manufacturing companies.

## Dependencies
This project assumes that you have <a href="https://github.com/SimulationEverywhere/cadmium" target="_blank">**Cadmium (DEVS IO version)**</a> installed in your home directory (i.e., one folder up than the ABAMCA project)

## Build and Execute
To build this project, run:
```sh
source run_action_rt.sh
```
Note: You need to send the input using a separate terminal opened in the TCPclient folder.
Sample commands with the data are available in TESTING_INPUT_MANUAL
