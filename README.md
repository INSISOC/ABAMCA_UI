# ABAMCA PROJECT

## Introduction


## Dependencies
This project assumes that you have Cadmium (DEVS IO version) installed in your home directory (i.e., one folder up than the ABAMCA project)

## Build and Execute
To build this project, run:
```sh
source run_action_rt.sh
```
Note: You need to send the input using a separate terminal opened in the TCPclient folder.
Sample commands with the data are available in TESTING_INPUT_MANUAL
